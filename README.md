# Berrus desktop

Downloads for the Berrus desktop app. The game itself runs at
**[berrus.app](https://berrus.app)**: the app is the same game with graphics
tuned for your computer, and your account and progress are shared everywhere.

## Download

| System | File |
| --- | --- |
| Windows | [Berrus-windows-setup.exe](https://github.com/jvidalv/berrus-desktop/releases/latest/download/Berrus-windows-setup.exe) |
| macOS (Apple Silicon, M1 and newer) | [Berrus-mac-arm64.dmg](https://github.com/jvidalv/berrus-desktop/releases/latest/download/Berrus-mac-arm64.dmg) |
| macOS (Intel) | [Berrus-mac-x64.dmg](https://github.com/jvidalv/berrus-desktop/releases/latest/download/Berrus-mac-x64.dmg) |
| Linux | [Berrus-linux.AppImage](https://github.com/jvidalv/berrus-desktop/releases/latest/download/Berrus-linux.AppImage) |

Or pick your system at [berrus.app/download](https://berrus.app/download).
Prefer Steam? [Berrus on Steam](https://store.steampowered.com/app/4126930/Berrus/).

## First launch

- **Windows:** if it says Windows protected your PC, click **More info**, then
  **Run anyway**.
- **macOS:** if the app is blocked, open **System Settings → Privacy &
  Security** and click **Open Anyway**.
- **Linux:** make the AppImage executable (`chmod +x Berrus-linux.AppImage`),
  then open it.

The Windows and Linux apps update themselves. On macOS the app tells you when a
new version is out.
